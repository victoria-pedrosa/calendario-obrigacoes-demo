# Demonstração — Calendário de obrigações e certificados digitais

> Projeto de portfólio de **Victória Pedrosa**. **Demonstração** de calendário de obrigações e certificados digitais — versão com dados fictícios (nomes, CNPJs, e-mails e IDs internos substituídos).

## Problema de negócio
Controle de obrigações tributárias e de certificados digitais dependia de planilhas desatualizadas.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Calendário e vencimentos de certificados controlados manualmente. | Script gera o calendário de eventos a partir das regras de obrigações e prepara a base de certificados para o AppSheet. |

## Ganho
- Prazos e certificados sob controle, sem vencimento esquecido.

## Tecnologias
Gatilhos agendados, Google Apps Script, Google Sheets

## Arquivos
- `CertificadosSetup.gs`
- `Codigo.gs`

## Como usar
Crie um projeto no Google Apps Script, copie os arquivos `.gs`/`.html` e configure as Propriedades do script indicadas no código.
